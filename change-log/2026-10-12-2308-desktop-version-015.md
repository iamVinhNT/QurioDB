# Desktop release 0.1.5

## Summary and reason

Bump QurioDB from 0.1.4 to 0.1.5 for the release that adds native macOS CI builds. The user authorized committing, pushing, and releasing the new version from the current branch.

## Files changed

- Root `.env` (local, gitignored): set `QURIODB_VERSION=0.1.5`.
- `apps/desktop/package.json`, `apps/desktop/src-tauri/tauri.conf.json`, `apps/desktop/src-tauri/Cargo.toml`, and `apps/desktop/src-tauri/Cargo.lock`: synchronize package and bundle versions with `bun run version:sync`.
- `README.md` and `apps/desktop/README.md`: synchronize documented version and existing installer links.
- `CHANGELOG.md` and this detail file: record the version change.

## Impact

- Desktop: native Windows, Linux, and macOS bundles use version 0.1.5.
- API, UI, and data: no source behavior, response contract, or schema changes in this version bump.
- Release: the `v0.1.5` tag triggers the desktop release workflow. Publishing requires every native build to succeed.

## Verification

- `bun run version:sync`: synchronized the six managed version targets.
- `bun run version:check`: passed; all managed targets match 0.1.5.
- `bun test scripts/sync-version.test.ts`: 18 passed, validating version synchronization and release workflow guards.
- `cd apps/desktop && bunx vitest run`: 21 desktop configuration tests passed.
- `actionlint .github/workflows/release-desktop.yml` and `git diff --check`: passed.
- Native build and packaged-app verification depend on the tagged CI run and the target operating systems. No local native macOS or Windows build was run from this Linux workspace.
